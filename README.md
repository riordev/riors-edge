# Rior's Edge

A first-person looter shooter with ARPG progression and MMO social structure,
built in Unreal Engine 5.8. Private repository; its readers are the owner and
the agents working on it.

`Docs/VISION.md` says what the game is. `Docs/spec/` says how each system is
meant to work — seven files, present tense, intent only. `Docs/DECISIONS.md`
holds the live rulings and the open questions. `Docs/STATE.md` says what is
actually true right now, and is generated:

```bash
python Scripts/status.py
```

`CLAUDE.md` carries the working rules — how to build, how to run the suite,
how to photograph the game, and the discipline that keeps the documentation
from growing back.

`Assets/` holds source material rather than documentation: the owner's story
document and the design canvases the interface is transcribed from.
