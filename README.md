# Rior's Edge / Project Breaker

Unreal Engine 5.8 project for a fast, movement-driven ARPG looter shooter.

The existing First Person template remains the playable baseline. New reusable systems live in C++ under `Source/RiorsEdge`; game content belongs under `Content/ProjectBreaker` as it is created.

See `Docs/Setup.md` before opening the project on a new computer.
The implementation sequence and milestone gates are in `Docs/Roadmap.md`.
Agents and contributors should read `CONTEXT.md` before changing the project.
The Godot prototype's confirmed behavior and Unreal recommendations are in `Docs/Godot-Mechanics-Audit.md`.
