# Feel — the suite no machine can run

The automated suite proves the game is CORRECT. It cannot prove it is good. It
cannot judge weapon satisfaction, movement flow, encounter rhythm, spatial
readability, reward excitement, or whether a build choice felt transformative.
This file is the other suite, and only the owner can run it.

## How it is used

The owner plays, then fills in a session below — newest at the top. The seat
reads THIS FILE FIRST, before `.claude/DESK.md`, and the next cycle's work is
chosen from it: **the lowest-scoring beat that names a one-thing wins.** A desk
item never outranks a red beat here.

Two rules that keep it useful:

- **"It felt bad" is not actionable. "It should feel X, it felt Y" is.** That
  is why every beat carries a MEANT TO FEEL line. Those lines are drafted from
  `Docs/VISION.md` and they are drafts — overturn any of them in place, and the
  overturn is the more valuable half of the entry.
- **Score against the target, not against a finished game.** A beat is not a 2
  because the art is grey. It is a 2 because the thing it is trying to do did
  not happen.

**The scale.** 1 actively bad, it made me want to stop. 2 wrong, and I can say
why. 3 inert — nothing wrong, nothing there. 4 good, wants sharpening. 5 I
would show someone this.

A 3 is the most dangerous score in the file. It means the beat is not broken
and not doing anything, which is how a slice ends up correct and dead.
