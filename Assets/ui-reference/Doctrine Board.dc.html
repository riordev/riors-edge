The shape of adjacency
Eight nodes on a three-column, three-row lattice, and every link is a horizontal or vertical run — where two nodes do not share an axis the route takes exactly one right angle, never a diagonal. The two stat nodes sit at the left edge and are open on commit, so the board has two entry points rather than a granted node. Links go cyan when both ends are owned, so the owned set reads as a lit run; a half-owned link goes gold, which is the frontier drawn rather than annotated.
Pricing on the board
26 points offered per doctrine: 2 stat at 1, 5 rule at 2 with a further 2 to upgrade, keystone at 4. Cost sits beside the name at every state, so the board is priced before anything is clicked. Rule nodes carry two rank pips — the second rank is a purchase on the board, not a hidden tier — and their state line reads RANK 1 OF 2 while the upgrade is still open. Nothing is gated by points invested; price is the only cost.
One pool, one counter
The header shows a single skill-point balance against the 65-point lifetime pool, shared with the Core tree, and one respec that clears everything. There is no doctrine currency and no class currency. The rail's per-doctrine bar is spend, not a second budget — it reports where the shared pool went.
