# Vertical slice

The first slice proves movement and item feedback in one graybox arena: sprint, dash, slide, grapple; three weapons; three enemies, one elite, one boss; basic GAS health/damage/cooldowns; randomized loot with three legendaries; about 15 skill nodes; and save/load.

Done means a fresh player can enter, learn movement, defeat enemies, equip randomized loot, choose a skill, defeat the boss, quit, and resume—with a clean clone building on both macOS and Windows.
